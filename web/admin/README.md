# AsaPhis Admin Web

This directory is the production boundary for the internal AsaPhis admin application.

Planned responsibilities include:

- Content publishing and education library management
- Community moderation and submission review
- Member verification and access review
- Contribution, travel access, and support operations
- Audit history and role-based administration

The user-facing application does not depend on this directory. Build the admin app here when its authorization model and operational workflows are defined.
